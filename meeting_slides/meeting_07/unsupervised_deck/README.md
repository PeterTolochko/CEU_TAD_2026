# Unsupervised learning slides

Compile `unsupervised.tex` with LuaLaTeX, for example:

```sh
lualatex unsupervised.tex
```

Run the command from this folder. A standard LaTeX installation with Beamer and pdfpages is required. No other course files are needed. Compilation creates the usual LaTeX auxiliary files and extracts an embedded PDF containing the retained 2025 slides.

The opening slides and the revised Dirichlet prior slide are editable LaTeX. The retained 2025 slides are embedded PDF pages and cannot be edited as LaTeX.
