# Figure source

`michel2011_figure4.png` is an unchanged copy of
`methodsnet_2026/classes/day_1/figures/quant_analysis_1.png`, also shown in the
2025 introductory lecture. It contains panels A–D from Michel et al. (2011),
Figure 4, DOI: https://doi.org/10.1126/science.1199644.

The Beamer source displays only panel A using a presentation crop. Both axes,
the language legend, and the highlighted period are retained. The x-axis title
“Year” is set directly beneath the image so neighbouring-panel text can be
excluded from the crop. No data are redrawn.

`barbera2015_networks.png` is an unchanged copy of
`methodsnet_2026/classes/day_1/figures/aps_2.png`, also shown in the
2025 introductory lecture. It reproduces the network comparison used for
Barberá et al. (2015), *Tweeting From Left to Right: Is Online Political
Communication More Than an Echo Chamber?*, Psychological Science 26(10),
1531–1542. DOI: https://doi.org/10.1177/0956797615594620.
The slide displays the complete image; no event labels have been inferred
for its individual panels.
