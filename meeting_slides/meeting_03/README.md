# Class 3 — The Federalist Papers

This class applies the count, vector, multinomial, log-odds, and preprocessing ideas from Classes 1–2 to the Federalist Papers authorship problem.

- `main.tex` / `main.pdf`: lecture slides
- `meeting_03.ipynb`: practical notebook
- `federalist.csv`: local teaching copy of the essay data
- `figures/`: course images used in the slides. The files ending in `_2025` are extracted from the CEU 2025 Federalist deck (`../CEU_2025/meeting_slides/meeting_03/text_as_data_03.pdf`) and retained here as local teaching assets.

The analysis uses the source labels in `federalist.csv` without overriding them. Although paper 58 is historically disputed, the supplied data label it `MADISON`, so it is part of the Madison reference set in the slides and notebook.
