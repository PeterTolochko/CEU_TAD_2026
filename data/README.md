# Class 1 speech sample

`sotu_sample.csv` contains four full speech texts selected from
`methodsnet_2026/materials/data/sotu.csv`: 2008, 2010, 2016, and 2020.

The sample keeps `president`, `year`, `party`, `sotu_type`, and `text` unchanged.
`source_row_id` preserves the original `X` column. The source's `years_active`
field is not included. The rows were selected for a small classroom example,
not as a representative sample of presidents, parties, or years.

The MethodsNET data README identifies `sotu.csv` as “Legacy course material”.
It does not identify the original archive. That provenance remains unresolved.
